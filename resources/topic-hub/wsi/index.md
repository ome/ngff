# Whole Slide Imaging

Resources related to Whole Slide Imaging (WSI) and its use in the context of the NGFF.

- [wsidata: Efficient data structures and IO for whole slide image analysis](https://wsidata.readthedocs.io/en/latest/index.html#)

Storage backed by [SpatialData](https://spatialdata.scverse.org/).

# Tools

- [raw2features](https://github.com/CraigMyles/raw2features)

Utility for generating embeddings from whole slide images saved in OME-Zarr format.
